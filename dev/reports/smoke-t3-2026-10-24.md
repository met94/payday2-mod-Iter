# Smoke report — T3 first AI run, 2026-10-24

Build: `ef55142`. Log: `2026_10_24_log.txt` (117 KB).
Maps: Hotline Miami D1 (`mia_1`), Biker Heist D1 (`born`).
Card `T3-navlink`: FAIL (missing heartbeat events), no Iter errors.

## What passed

- `nav_ai=true` boot; overlay/shim/proxies active:
  - `mia_1`: 101 segments, 2009 rooms, 3380 doors, 124 door pairs,
    `no_doors=0`, proxy choke=89, in=42, out=140.
  - `born`: 53 segments, 3407 rooms, 6274 doors, 42 door pairs,
    `no_doors=0`, proxy choke=17, in=11, out=41.
- `!iter links` registered 133 and 79 nav-link elements. Interval
  derivation works on real data: `e_nl_up_1_down_5m` 2.00,
  `e_nl_down_2m` 1.50, `e_nl_down_4m_jump` 1.00,
  `e_nl_climb_over_3m` 2.00.
- No `[ITER-ERR]`, no FATAL, no Iter Lua traceback. The three Lua errors
  are BeardLib `ModAssetsModule.lua:156`.

## What the card could not prove

- `!iter ai` reported `total=38 travelling=0 coarse_path=0` on Hotline and
  `total=34 travelling=0` on Biker. The harness read `data.brain` from
  `EnemyManager:all_enemies()`, but that table stores `{unit=...}`, not a
  brain. The diagnostic was wrong, not necessarily the AI.
- No `evt=navlink` / `evt=summary` lines: the build only emitted them from
  `on_simulation_ended`, which did not run when quitting to desktop.
  Therefore the T3 card had no `navlink.elements`/`summary` fields.
- Queue/reservation state was all zero. This is inconclusive: the run had no
  proof that `navlink_queue` was enabled, and the two maps may not have used
  a ladder in the 60 s window.

## Fixes in the next build

- `!iter ai` now resolves `unit:brain()` from `data.unit`.
- Boot event logs `navlink_queue`, `path_extender`, `direct_to_pos`.
- 30 s heartbeat emits `evt=navlink` (elements/queued/reserved) and
  `evt=summary` (all counters), so a log is useful even on a hard quit.
- Counters: `navlink_prepare`, `navlink_reserve_ok/busy/free/own`,
  `navlink_switch_ok/fail`, `search_ok/fail/cache_hit/cache_fail`,
  `direct_to_pos`.
- Coarse cache cleared on `_clear`, `set_nav_segment_state`, `clbk_navfield`.
