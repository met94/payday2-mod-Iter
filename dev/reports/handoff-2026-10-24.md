# Handoff — build 04477d3 (T6 map patches)

## What changed

`_navdatapatches.lua` now selects the level **at heist load time** instead of
file-load time:

- one `set_load_data` wrapper;
- gates: `map_patches`, data version < 6, `door_low_rooms`, per-level
  `map_change_*`, CRC;
- `evt=patch level=<id> result=applied|mismatch|skip_version|skip_setting|skip_nopatch`;
- `!iter patch` shows the last status;
- helpers (`append_room`, `append_door`, `transfer_room`, `append_vis_group`,
  `add_segment`) are prepared per load.

Offline wrapper test: 12 checks PASS. Static gates PASS.

## Test (one heist, ~3 min)

1. Install `dist/Iter` at `04477d3` (harness unchanged).
2. Mod Options → Iter → enable **Dev: v6 map patches** (all other toggles
   unchanged).
3. Load **Big Bank**.
4. Type `!iter patch` and `!iter nav`.
5. Quit and send the log.

Expected:

```
[ITER-NAV] evt=patch level=big result=applied|mismatch|skip_...
[ITER-TEST] patch level=big result=...
```

- `applied` = CRC matched and the patch ran.
- `mismatch` = nav data drifted; patch skipped safely (we then re-derive the
  signature or drop that level's patch).
- `skip_version` / `skip_setting` = expected alternatives.

No crash. If it crashes, send `crash.txt` and the log.
